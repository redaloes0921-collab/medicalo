# MEDICALO 콘텐츠 팩토리 — AI 광고 소재 자동 생성 시스템

기존 메디컬오 광고 자산(이미지·영상)의 스타일을 학습해, 광고 소재(이미지)와
쇼츠 영상(YouTube Shorts / Meta Reels / TikTok)을 **매일 자동으로 기획·생성**하는
파이프라인입니다. 목표 기간: 3개월 (2026-07-26 ~ 2026-10-26).

## 폴더 구조

| 경로 | 설명 |
|------|------|
| `brand-profile.md` | 브랜드 스타일 프로필 — 모든 AI 생성의 기준 (컬러/타이포/톤/카피 규칙) |
| `asset-inventory.md` | 학습용 기존 광고 자산 목록 (Google Drive 파일 ID 포함) |
| `compliance.md` | 의료광고 규제 체크리스트 — 소재 게시 전 필수 검수 |
| `prompts/` | AI 생성 프롬프트 템플릿 (이미지 광고 / 쇼츠 스크립트 / 영상) |
| `daily/YYYY-MM-DD.md` | 일일 콘텐츠 플랜 — 매일 자동 생성되는 소재 기획안 |
| `output/` | 생성된 소재 기록 (URL/메타데이터, 실제 파일은 생성 플랫폼에 보관) |

## 일일 자동화 파이프라인

매일 아침 9시(KST) 자동 실행되는 루틴이 다음을 수행합니다:

1. **기획** — `brand-profile.md` + `prompts/` 템플릿 기반으로 오늘의 소재 3종 기획
   - 이미지 광고 1종 (Meta/인스타 피드용 1:1 또는 4:5)
   - 쇼츠 스크립트 1종 (15~30초, 훅-본문-CTA 구조, 3플랫폼 공용)
   - 시즌/트렌드 반영 소재 1종 (계절·이벤트·트렌드 연계)
2. **생성** — 크레딧 잔량 확인 후 이미지 초안 생성 (1일 최대 2장, 크레딧 부족 시 기획안만)
3. **기록** — `daily/YYYY-MM-DD.md`로 커밋 & 푸시
4. **알림** — 완료 시 푸시 알림

> 사람의 역할: 매일 생성된 기획안/초안 중 **선택·승인**만 하면 됩니다.
> 승인된 소재는 `compliance.md` 체크 후 집행합니다.
