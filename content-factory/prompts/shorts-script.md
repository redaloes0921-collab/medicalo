# 쇼츠 스크립트 템플릿 (YouTube Shorts / Meta Reels / TikTok 공용)

길이 15~30초, 9:16 세로. 구조는 브랜드 프로필의 훅-원리-해결-CTA.

## 스크립트 포맷

```
제목: (내부 관리용)
타깃: (예: 20-30대 여성, 기미 재발 경험자)
길이: XX초

[훅 | 0-1.5초]
자막+나레이션: (고민을 찌르는 질문/반전. 예: "레이저 했는데 기미가 또 올라왔다면?")
화면: (첫 프레임 비주얼 — 스크롤을 멈추게 하는 것)

[원리 | 1.5-15초]
나레이션: (왜 그런지 원리 설명 — 전문성이 신뢰를 만든다)
화면: (다이어그램/B롤/원장 클립)
자막 키워드: (레드 강조할 단어)

[해결 | 15-25초]
나레이션: (메디컬오의 접근 — 진단 중심, 유형별 맞춤)
화면: (클리닉/진단 장비/프로그램 카드)

[CTA | 25-30초]
자막: (예: "내 색소 유형이 궁금하다면 → 프로필 링크")
화면: (로고 + 슬로건 FACE, YOUR LIFE)

※ 개인차 문구 자막 포함
```

## 포맷 3종

1. **정보전달형 (Faceless)** — AI 생성 B롤 + 자막 + TTS 나레이션. 완전 자동화 가능. 1순위 양산 포맷
2. **원장 설명형** — 기존 인터뷰/컷편 영상에서 클립 추출(personal_clipper) + 자막. 신뢰도 최고
3. **스토리형** — 고민 시작 → 진단 → 관리 여정. AI 영상 생성 + 나레이션 (전후 연출은 compliance 주의)

## 플랫폼별 변주

- **TikTok**: 훅을 더 캐주얼하게, 트렌드 사운드 실험 가능, 해시태그 3~5개
- **YouTube Shorts**: 정보 밀도 높게, 제목에 검색 키워드 (기미, 색소침착, 모공)
- **Meta Reels**: 광고 전환 목적이면 개인 단정 표현 금지 ("당신의" → "혹시 이런 고민")

## 주제 뱅크 (매일 여기서 선택하거나 추가)

우선순위: **메인 = 모공·흉터 (60~70%), 서브 = 색소/기미 (30~40%)** — brand-profile.md 참조

### 메인 — 모공·흉터

- 피지형 모공 vs 흉터형 모공 구분법
- 모공이 세로로 늘어났다면 봐야 할 것 (탄력저하형)
- 모공 패키지 왜 "특허 모공 주사"부터 시작하나 (프로그램 해부 시리즈)
- 블랙헤드 짜면 모공이 넓어지는 진짜 이유
- 여드름 흉터, 시간이 지나면 옅어질까? (파인 흉터의 원리)
- 흉터 재생 박리술이 뭐길래 (시술 원리 설명형)
- 모공은 "닫는 게" 아니라 "채우는 것"인 이유
- 세안을 열심히 해도 모공이 그대로인 이유
- 20대 모공과 30대 모공, 치료가 달라야 하는 이유 (탄력)
- 흉터형 모공에 일반 레이저가 안 통하는 이유

### 서브 — 색소·기미

- 지워도 다시 올라오는 기미의 진짜 이유
- 기미 vs 주근깨 vs 잡티, 내 색소는 뭘까 (유형 진단 시리즈)
- 색소는 "없애는 게" 아니라 "다스리는 것"인 이유
- 여름 자외선 후 가을이 색소 치료 골든타임인 이유
- 레이저를 세게 쏘면 안 되는 피부 타입

### 공통 — 신뢰/브랜딩

- 원장이 말하는 "치료보다 중요한 재발 방지"
