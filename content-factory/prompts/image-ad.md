# 이미지 광고 생성 템플릿

`brand-profile.md`의 공통 스타일 토큰을 항상 포함할 것. 규격: Meta/IG 피드 1:1(1080×1080)
또는 4:5(1080×1350), 스토리·쇼츠 커버 9:16(1080×1920).

## 유형 1 — 가격표형 (기존 KR ver1.0 패턴)

텍스트 렌더링이 필요한 소재는 AI 원본 생성보다 **배경/비주얼만 AI 생성 후
Canva에서 텍스트 오버레이** 방식을 기본으로 한다 (한글 타이포 품질 보장).

```
[공통 스타일 토큰] + soft abstract skincare-themed background, subtle gradient
from white to warm light gray, gentle light rays, space reserved at top for
headline text, product-free, calm premium spa atmosphere
```

## 유형 2 — 프로그램 소개형 (원리/진단 강조)

```
[공통 스타일 토큰] + [인물 토큰] + close-up of clear healthy skin on cheek,
soft focus, dermatology diagnostic mood, subtle skin-layer diagram aesthetic,
scientific yet warm
```

카피 구조: 문제 제기(색소는 표면이 아니라 뿌리) → 유형 진단 → 프로그램명 + CTA

## 유형 3 — 시즌 프로모형

```
[공통 스타일 토큰] + seasonal element ([계절 키워드: summer sunlight / autumn
light / winter care]), red accent (#DE3E28) badge area, promotional energy
but still minimal and premium
```

카피 구조: 시즌 훅(자외선이 강한 계절) → 한정 패키지 → 할인 표기(회색 취소선 + 레드)

## 유형 4 — 신뢰형 (연구/장비/원장)

```
[공통 스타일 토큰] + clean modern medical clinic interior, white and warm wood
tones, soft daylight through windows, professional dermatology equipment
subtly visible, trustworthy calm atmosphere
```

## 금지 사항

- 실제 시술 결과처럼 보이는 AI 전후사진 생성 금지 (compliance.md)
- 레드 남용 금지 — 포인트 1곳만
- 한글 텍스트를 AI 이미지에 직접 렌더링하지 않기 (오탈자 위험) → Canva 오버레이
