# MEDICALO — 색소 프로그램 랜딩 + 랜딩 에디터

메디컬오 스타일의 색소(기미·주근깨·잡티) 랜딩페이지와,
블록 단위로 콘텐츠를 관리할 수 있는 랜딩 에디터(admin)입니다.

## 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 랜딩페이지 (섹션/블록에 `data-lp` 태깅) |
| `admin.html` | 랜딩 에디터 — 미리보기 + 블록 트리 관리 |
| `js/lp-runtime.js` | 저장된 편집 내용 적용 + 에디터 통신 런타임 |
| `css/style.css` | 랜딩 스타일 |
| `images/` | 이미지 (파일명 가이드는 `images/README.md`) |

## 에디터 사용법

1. 로컬 서버로 실행하는 것을 권장합니다 (저장 기능이 안정적으로 동작):
   ```bash
   python -m http.server 8000
   # http://localhost:8000/admin.html 접속
   ```
2. **좌측 미리보기** — 모바일 390 / 모바일 440 / 전체 폭 전환, 요소를 직접 클릭하면 해당 블록 편집기가 열립니다.
3. **우측 트리** — 그룹(섹션) ▸ 블록 구조.
   - 블록 클릭 → 편집기 열림 (텍스트는 HTML로 편집: `<br>`, `<b>` 등 사용 가능)
   - 이미지 블록 → URL 입력 또는 파일 선택(자동 base64 삽입)
   - `↑` `↓` 순서 이동 · `복제` · `삭제` (그룹 단위도 동일)
   - `적용` → 미리보기에 즉시 반영 (저장 전 상태)
4. **저장** — 브라우저(localStorage)에 저장되어 랜딩페이지에 자동 적용됩니다. `Ctrl/Cmd + S`도 지원.
5. **HTML 내보내기** — 편집 내용이 반영된 완성 `index.html` 파일을 다운로드. 배포 시 이 파일로 교체하면 됩니다.
6. **초기화** — 저장된 편집 내용을 모두 지우고 원본으로 복원.

> 저장은 브라우저 단위(localStorage)입니다. 다른 기기/브라우저에 배포하려면
> **HTML 내보내기**로 받은 파일을 서버의 `index.html`에 덮어쓰세요.
